# Project Feedback Video Script

Hello everyone. My name is Parth, and this is my Google Ads capstone project based on an imaginary online learning platform called SkillBoost Academy.

The objective of this project was to understand how a Google Search Ads campaign is planned, structured and optimized.

I selected Search Campaigns because users searching for specific courses already have learning intent. I created ad groups for Java, Python, AWS, DevOps and Web Development.

For the campaign strategy, I worked on keyword themes, match types, negative keywords, audience targeting, location targeting, budget allocation and bidding strategy.

The proposed budget was one thousand rupees per day for thirty days. I also created sample responsive search ads with relevant headlines and descriptions.

I designed a demonstration landing page for SkillBoost Academy. The page explains the courses, the value proposition and includes a demo registration form that demonstrates the conversion experience.

For reporting, I used simulated performance data because this is an academic practice campaign rather than a live advertising campaign. I analyzed impressions, clicks, CTR, CPC, conversions, conversion rate and cost per conversion.

The biggest challenge was deciding which keywords and audiences should receive priority while keeping the campaign structure focused. I learned that Google Ads is not only about creating advertisements. Keyword relevance, landing-page experience, conversion tracking and continuous optimization are equally important.

This project helped me understand how digital marketing can be measured using data and how campaign performance can be improved through testing and optimization.

Thank you for watching my project feedback video.
