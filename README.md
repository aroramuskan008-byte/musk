# SkillBoost Academy – Google Ads Capstone

This repository contains the academic project for a simulated Google Ads campaign for **SkillBoost Academy**, an imaginary online learning platform.

## Project
- Campaign type: Google Search Campaign
- Goal: Generate qualified leads and course registrations
- Target audience: Students and young professionals in India
- Main themes: Java, Python, AWS, DevOps and Web Development
- Planned budget: ₹1,000/day
- Planned duration: 30 days

## Contents
- `index.html` – responsive demonstration website
- `style.css` – website styling
- `docs/Google_Ads_Campaign_Final_Report.pdf` – detailed final report
- `video-script.md` – script for the required feedback video

## Important
Campaign performance figures in the report are **simulated academic examples**, not actual Google Ads results.

## Deployment
This is a static website and can be deployed on GitHub Pages, Vercel, Netlify or another static hosting service.
